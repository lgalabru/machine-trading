# Requests for discussion

Ideas before they are decisions: rough, possibly wrong, but precise about
the question they ask. An RFD starts as `idea`, moves to `discussion` while
someone works on it, and ends `adopted` (with the ADR that records the
decision), `parked` or `abandoned`, with the reason. Number them in order
and never reuse a number. Decisions themselves live in [`../adr/`](../adr/).
